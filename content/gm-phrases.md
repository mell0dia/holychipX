# GM Card — Approved Phrases

The daily GM card rotates through these. Phrases are DELETED from this file as
they are used, so nothing repeats and the file always shows what is left.
Survivors renumber themselves automatically.

Edit freely: delete a line to drop it, rewrite to taste, or add your own.
One phrase per numbered line. The `(HC0xx)` tag is the origin the post links
to — it is stripped before rendering and never appears on the card.

REVAMPED 2026-09-28 (tease style): each phrase opens a question, gives a hint,
and stops before the answer, so the reader clicks through to the origin.
Example: "What happens when the trees are gone? The AI is sorry... then it
looks at the sea." (HC015). Two per origin, HC000-HC041, none previously used.
The old list is in gm-phrases.pre-revamp-2026-09-28.bak.md.

When it empties, `pick_thought()` falls back silently to a whole random blog
paragraph. Refill before it runs dry.
