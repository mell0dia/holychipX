# GM Card — Approved Phrases

The daily GM card rotates through these (random pick, no repeats until the list cycles).
Edit freely: delete a line to drop it, rewrite to taste, or add your own.
One phrase per numbered line. The `(HC0xx)` tag is just the source for reference — it's ignored by the card.

Refilled 2026-09-09. Every line below is copied VERBATIM from that story's origin
blog — no paraphrasing — and none has been used on a card before. Lines at or
under 60 characters render in the big Press Start 2P font; longer ones use the
smaller body font, so the short ones hit hardest.

When this list empties, `pick_thought()` falls back to a whole random blog
paragraph, which is how earlier cards ended up 265 characters long. Keep it fed.
